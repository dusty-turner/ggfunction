# Benchmark and accuracy result artifacts

This directory stores manual validation outputs used by the manuscript tables.
They are not run during `R CMD check`.

The result files are generated by:

- `../accuracy-distribution-conversions.R`
- `../benchmark-ggfunction.R`

From the repository root, rerun them after installing the current local package
source:

```r
devtools::document()
devtools::install(dependencies = TRUE, upgrade = "never")
Sys.setenv(GGFUNCTION_WRITE_BENCHMARKS = "true")
source("inst/benchmarks/accuracy-distribution-conversions.R")
source("inst/benchmarks/benchmark-ggfunction.R")
```

The accuracy files record fixed-grid numerical error checks. The benchmark
files record `ggplot_build()` timing checks, not full device rendering time.
Each regenerated CSV records the script name, run date and time, platform, R
version, relevant package versions, grid details, benchmark iterations, and the
timed operation.

The manuscript reads the latest `accuracy-*.csv` and `benchmark-*.csv` files
lexicographically, so final submission builds should keep the intended output
files in this directory.
